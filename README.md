# 测试中台

**一款给测试工程师的 Windows 桌面工作台。** 把日常测试里散落各处的东西——账号密码、环境地址、接口调试、测试数据、缺陷统计、笔记周报——收进一个本地加密的应用里，不用再在浏览器书签、Excel、记事本和 Postman 之间来回切。

Electron + React 构建，所有数据只存在你自己的电脑上（AES-256-GCM 加密），没有任何云端和账号体系。

## 下载

到 [Releases](https://github.com/belldandy114/password-manager/releases/latest) 下载最新的 `PasswordManager-Setup-x.x.x.exe`，双击安装即可（Windows 10/11）。

应用内置更新检查，有新版本会提示一键下载安装；也可以在设置里配置国内下载加速源。

## 它能做什么

### 🔐 加密密码库（网址管理）

- 网址、账号、密码、备注集中管理，支持自定义字段、附件、收藏、密码历史
- **TOTP 动态验证码**直接在条目上显示倒计时，点一下复制
- 剪贴板复制密码后按设定秒数**自动清空**；闲置自动锁定，全局快捷键一键锁屏
- 批量导入导出（CSV / JSON），删除进回收站可恢复
- 按「系统」聚合的视图：一个系统的全部账号、环境、地址一屏看完

### 🌐 环境矩阵

把各系统的测试 / 预发 / 生产地址录进一张矩阵，**一键并发巡检**：哪个环境挂了、响应多慢，一眼可见；巡检结果有历史记录可回看。状态翻转时可弹系统通知。

### 🧪 接口调试

类 Postman 的完整体验：请求历史、环境变量、响应断言、JSON 结构快照比对、Cookie 会话保持、**WebSocket / SSE 长连接**、cURL 导入导出。

- 接口集合可**存为回归集**，到点自动跑，失败了发系统通知，两次结果自动比对差异
- 测试数据生成器产出的数据可**一键填进请求体**直接开测

### 🎲 测试数据生成

17 类常用测试数据：身份证（校验位正确）、手机号、姓名、银行卡（过 Luhn）、车牌、邮箱、IP、UUID、日期、边界值、SQL / XSS 注入载荷……还支持**自定义正则生成**和 16 个常用正则快捷模板。可导出 CSV / Excel / JSON / Markdown。

### 🐞 缺陷管理（禅道）

对接禅道：按产品拉取 Bug 列表、按提交人 / 模块 / 状态统计汇总、缺陷热力图；后台定时检查新 Bug 和长期未动的单子，**超期自动提醒**。周报页可以直接基于禅道数据自动成稿。

### 📝 测试笔记与周报

- Markdown 笔记：`Ctrl+V` 直接粘贴截图（加密存本地）、SQL 片段分类管理、任何笔记可**钉成桌面小窗**浮在旁边照着做
- 周报支持本地 Markdown，也可从禅道数据自动生成初稿

### 🧰 工具箱 & 更多

20+ 个测试常用小工具：JSON 格式化 / 差异比对、正则测试、时间戳转换、日志分析（含 Nginx 访问日志）、数据脱敏、编码转换、JWT 解析……另外还有：

- **代码调试**：跑 JS / Python / Java 片段，HTML 实时预览
- **压力测试**：JMeter 非 GUI 运行的图形封装，选脚本就能压
- **全局搜索**：`Ctrl+K` / `Ctrl+空格` 随时唤起，能搜网址、笔记、账号、接口、测试数据类型，支持 `tag:`、`@note`、`data:身份证` 这类过滤语法
- **提醒中心**：超期缺陷、不可达环境、久未备份，一处汇总，一键清除
- **附件管理**：全库截图 / 文件集中查看，未引用的孤儿附件一键定位清理

## 安全设计

- 数据全部落在本地，**AES-256-GCM** 加密，主密码经 PBKDF2 高强度派生，不联网上传任何数据
- 自动锁定（可配置时长）、剪贴板自动清空、托盘最小化、窗口防截屏（可选）
- 密码改密时全库重加密，支持安全词找回

## 技术栈

Electron 37 · React 19 · TypeScript · Vite · Zustand · Vitest（73 个文件 950+ 条单测 + 打包版 UI 回归）。
