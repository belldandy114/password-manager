## 四、批次交付纪律（重申）

- 一个批次两个任务（渲染层 / 主进程）时，**两个都绿才算该批完成**；渲染层先绿可以先报，但批次不结。
- 每批交付必须给 `commandsRun` 原始输出与 `acceptanceResults` 逐条对应；`changedPaths` 越 `inScope` 即不通过。
- `git diff --stat` 不得出现 `electron/vault-*.js`、`electron/ipc-entries.js` 的集合清单、`src/utils/collectionTrim.ts`；`VAULT_SCHEMA_VERSION` 不变。
