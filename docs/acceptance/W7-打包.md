### 8.9 一个探针层面的教训（不是产品问题，记下来免得下次返工）

本轮冒烟第一版 8 项是 **5 通过 / 3 失败**，三条全是**探针自己写错**，不是应用缺陷：
1. **页签不能按文字点**：`元素库 → POM` / `.jtl 指标` 里的 `→` 与全角空格让 `includes` 匹配失败 → 改成**按 `.pg .tabs .tab2` 下标点击**后 8/8。
2. **不要 monkey-patch `window.electronAPI.scanReveal`**：`contextBridge` 暴露的对象是**冻结**的，赋值静默失败（拿到的 `__revealLog` 永远是空）。改成看**副作用**（资源管理器窗口 + 选中项）。
3. **枚举资源管理器窗口别用 `Add-Type` + `EnumWindows`**：pwsh 7 下委托推断报 `CS7036`；改用 `Shell.Application` COM 一行拿到「路径 + 已选项」。
4. **「真的打开了」要有反例排除**：目标文件必须**点击前未被任何窗口选中**，否则读到的是上一轮留下的窗口，判据就是虚的（本轮第一版就差点这么过）。
