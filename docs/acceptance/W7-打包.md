### 6.2 已知问题与规避（继承自 W7 集成验收，未在打包环节新增）

| # | 现象 | 规避 |
|---|---|---|
| 1 | **SmartScreen「未知发布者」**：本 exe 用 signtool 做了资源完整性签名但**没有代码签名证书**，首次运行 Windows 会拦 | 点「更多信息 → 仍要运行」；或提前对目录做 `Unblock-File` |
| 2 | 杀软可能对「临时目录里的 exe」敏感（历史教训：应用内下载曾把安装包拼到 `%TEMP%` 被隔离） | 本交付物在 `release\` 下，不在 `%TEMP%`；若被隔离请把目录加白名单 |
| 3 | 若在**别的目录树**里重新打包后双击闪退（退出码 `2147483651`） | 见 §3.3：`icacls … /setintegritylevel (OI)(CI)Medium /T` 后复核 |
| 4 | 生效范围：本 exe 是**解压版**，没有安装/卸载/自动更新链路 | 需要安装包再出 NSIS（要设 `ELECTRON_BUILDER_CACHE`） |

### 6.3 未覆盖 / 未验证（照实写）

1. **只测了解压版**：NSIS 安装包（安装到 `Program Files`、开始菜单快捷方式、卸载器、应用内更新）**本轮没做也没验**。
