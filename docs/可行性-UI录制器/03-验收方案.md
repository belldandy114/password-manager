## 1. 判定口径（怎么算「这条能验收」）

| # | 判据 | 二值问法（答「是」才通过） |
|---|---|---|
| 1 | 二值化 | 两个人读同一条，是否只能得出同一个「满足 / 不满足」结论，不需要再讨论「算不算基本满足」 |
| 2 | 可测 | 能否写出「输入 / 动作 / 判定动作」三件套：用哪份数据、谁做什么、由谁执行哪个判定动作 |
| 3 | 可观测 | 判定依据的那个信号**现在真的存在**，且评审者拿得到（选择器 / 字段名 / 命令 / 文件路径） |
| 4 | 无隐含前提 | 标准成立依赖的前提（登录态 / 数据存量 / 环境 / 端与版本 / 时序）写在标准里，不靠读者默认 |
| 5 | 归属明确 | 谁判定、在哪判定、什么时候判定，三问都有答案 |

**结论只允许三种**：可验收 / 驳回 / UNKNOWN（UNKNOWN 必须写清缺什么才能判定，**不等于通过**）。
**驳回必须三段齐全**：逐字引用原话 → 违反哪条判据 → 要求改成什么样（缺任何一段，这条驳回无法复核）。
**数值来源**：本文出现的所有阈值/数量/时限，要么来自 `01-方案` / `05-视觉约束` 原文，要么由本轮实测得出（§7 / §8），或明确标「本项目自定」并给出依据。**没有编造的数字**。

### 5.5 新增两条本期特有判据（细则）

**AC-20 · 三份产物同源（机器判据）**

- **为什么新增**：`01-方案` 的 AC-10c 只写了「步骤条数与定位器逐条一致」，没给抽取口径（见 D-11）。本条把同一断言变成可机器判定的形态。
- **要求**：S6 必须抽出一个纯函数（暂名 `stepsToCalls(rec)`）返回 `{ action, locatorValue, valueRef? }[]`，三个模板都由它 reduce 生成。
- **判定动作**（`recordScript.test.ts` + 验收脚本）：
  1. 取 `buildMjsScript(rec)` / `buildSpecTs(rec)` / POM 行（`pageobject.ts` 的 `PomElementRow.locator`）；
  2. 按**源码出现顺序**抽出所有 `locator.value` 字符串为数组 `A_mjs` / `A_spec` / `A_pom`；
  3. 断言 **`stripPreamble(A_spec).length === rec.steps.length`**（**产物② `.mjs` 本期不交付，已从三选降为两选**，见 AC-10a；等 P3 恢复时再按三数组判）；t32 之后产物会带一条 `preamble:true` 的起始导航（`index:-1`、不是 `UiStep`），**必须先剥离再比长度**，否则 7 ≠ 6 会假红；**POM（产物①）按 J-15 单独判**——POM 的结构里没有「步骤」，只有元素集合，所以 ① 的判据是「`elements[]` 与 `steps[].elementId` 一一对应（数量相等 + `elements[].locator` 与对应步骤的定位器逐条相等）」，**不参与「三数组等长」这个断言**（按字面判 ① 永远判不通）；
  4. 断言三个数组**逐元素字符串相等**（`value` 是唯一的，故顺序即一致性证明）；
  5. 断言 `rec.steps[i].index === i`（升序连续）。
- **证伪**：任一数组长度不等；任一位置字符串不等；顺序不同；POM 的 `elements[]` 行数 ≠ 步骤数。
- **降级条款**：若 S6 未抽中间表示，本条**记「未验证」**，不得用「三份看起来一样」替代。

**AC-21 · 录制期不落盘（只有点「保存」才写一次 vault）**

- **为什么新增**：`00-归口` §2.5 写了「录制过程不落盘，仅在「保存」时写一次」，但 `01-方案` §7 的 AC 表里**没有对应条目**；这条是本期数据安全与「录制中途崩溃可重来」的基础。
- **判定动作**：
  1. 用隔离数据目录（`prepareDataDir`），取 `vault.enc` 的 `sha256` 为 H0（`Get-FileHash`）；
  2. 点「开始录制」→ 录 ≥5 步（含 fill/select，步骤数在界面上 > 0）→ 点「停止」；
  3. 再取 `sha256` 为 H1，断言 **H1 === H0**；
  4. 点「保存」→ 取 H2，断言 **H2 ≠ H1** 且 `ws:get('uiRecordings').length` 比保存前 **+1**；
  5. 另断言：保存前 `ws:get('uiRecordings')` **读不到**本次录制（它是内存态）。
- **证伪**：录制期 H1 ≠ H0；保存后 H2 === H1；保存后条数 +0 或 +2；保存前就能读到本次录制。
- **口径说明（为什么不数「写了几次」）**：`writeFileAtomic` 的写盘路径是「临时文件 → fsync → rename + `.bak`」，会产生 2~3 个 `rename` 事件，用 `fs.watch` 事件数当「写了 1 次」会**误判**。故「只写一次」的严格证明按设计约定记账（写盘入口唯一 = `saveVault`），机械断言只覆盖「录制期零变化 + 保存后恰一次条数增加」这两条。
- **归属**：qa / 开发目录+dist / W2（S3 落地后即可验）。`vault.enc` 路径见 `electron/main.js:113`（`path.join(DATA_DIR, 'vault.enc')`）。

### 6.1 几何断言（AC-15 / AC-19 的压盖与截断）

```js
// 表达式在页面上下文执行；PASTE 到验收脚本的 ev() 里
const GEOM_EXPR = `(() => {
  const ROOT = '.pg.rec-page';
  const SEL  = 'input, select, textarea, button';
  const vis = (el) => {
    const cs = getComputedStyle(el), r = el.getBoundingClientRect();
    return r.width > 0 && r.height > 0 && cs.visibility !== 'hidden' && Number(cs.opacity) > 0;
  };
  const els = [...document.querySelectorAll(ROOT + ' ' + SEL)].filter(vis);
  const rects = els.map((el) => {
    const r = el.getBoundingClientRect();
    return { tag: el.tagName, cls: String(el.className).slice(0, 40),
             x: r.left, y: r.top, w: r.width, h: r.height };
  });
  // 1) 两两相交：重叠面积 > 0.5 px² 判失败（0 px 相邻允许）
  const overlaps = [];
  for (let i = 0; i < rects.length; i++) {
    for (let j = i + 1; j < rects.length; j++) {
      const a = rects[i], b = rects[j];
      const ox = Math.min(a.x + a.w, b.x + b.w) - Math.max(a.x, b.x);
      const oy = Math.min(a.y + a.h, b.y + b.h) - Math.max(a.y, b.y);
      if (ox > 0 && oy > 0 && ox * oy > 0.5) overlaps.push({ a, b, area: +(ox * oy).toFixed(2) });
    }
  }
  // 2) 溢出裁切：容器 scrollWidth <= clientWidth + 1
  const overflow = [...document.querySelectorAll(ROOT + ' .pnl-body, ' + ROOT + ' .pnl, ' + ROOT + ' .dev-scroll, ' + ROOT + ' .rec-scroll')]
    .filter(vis)
    .map((el) => ({ cls: String(el.className).slice(0, 40), sw: el.scrollWidth, cw: el.clientWidth }))
    .filter((o) => o.sw > o.cw + 1);
  // 3) 按钮文字被挤成半截（1.9.2 踩过）
  const clipped = els.filter((el) => el.tagName === 'BUTTON')
    .map((el) => ({ txt: (el.textContent || '').trim().slice(0, 20), sw: el.scrollWidth, cw: el.clientWidth }))
    .filter((o) => o.sw > o.cw + 1);
  return { n: rects.length, overlaps, overflow, clipped };
})()`;
```

## 9. 必须写进文档的坑（照抄不许省）

### 9.1 `ui-glass-opaque-scan.js` **不在** `npm run check` 里

`npm run check` → `scripts/preflight.js` → `scripts/ci-gate.js`，实际跑的是：privacy / tsc / electron `node --check` / vitest / check:ipc（+自测）/ check-css-dup / check-z-index（+自测）/ check-stacking（+自测）/ css-cascade-audit / check-debt-budget。
**玻璃扫描一条都没跑**（`05-视觉约束` §5 与脚本头注释都写明「要单独跑」）。漏跑 = 玻璃门禁假绿：`npm run check` 全绿只能说明另外三道门绿。

### 9.2 新页未加进 `PAGES` 时「0 违规」是**假绿**

该脚本是**按 `PAGES` 白名单逐页扫**的。录制页不登记，脚本照常 `exit 0` 并打印「0 违规」——但它**一条都没扫录制页**。
自证机制（缺一条，登记就等于自欺）：

1. `PAGES` 里加录制页，并写 `min`（该页「必须有多少个内容元素」才算真的渲染出来了）；
2. 写一条 `READY_PRED`（**与当前 tab 无关**，否则「切 tab」是下一步动作 → 死锁；本仓 1.32.3 / 1.32.5 踩过两次）；
3. 写一条 `APPLIED_PRED`（点完 tab/按钮后真的切过去了）；
4. `TARGETS` 至少一条锚点**带 `token`**（只验 `alpha < 1` 拦不住假绿：`.pager` 的基础底色本来就是半透明）。

**验收时的分母判据**：日志末尾必须打印 `扫描 N 个「主题 × 页面/弹窗」组合`，且 **N ≥ 36**（基线 32 + 录制页 2 单元 × 2 主题）。N 不涨 = 录制页根本没进扫描，**直接判 AC-17 失败**。
