### 2.2 验收标准

可判定条目以本目录 `01-方案-本期P0.md` §7 的 AC 表为准（每条带**分母 + 判据 + 证伪形态**）。
**不采用**「体验良好」「正常可用」这类无法判真假的表述。

### 2.3 技术约束

- Electron **37.10.3**（固定）、React 19 + Vite、Zustand；渲染层 `types: []`（不引 Node 类型）。
- 零新增运行时依赖（录制链路只用 Node 内置 `fetch` / `WebSocket`）。
- 主进程新模块**不许碰** `MAIN_ONLY_STATE`（`mainWindow` / `loadVault`…），一律 getter 注入。
- 新 IPC 四件套必须同步：`electron/ipc-record.js` → `preload.js` → `src/types.ts` → `check:ipc`。
- 样式只许追加到 `src/styles/redesign.css` 末尾（三份 CSS 级联冲突 253 处，不得改动前两份的优先级）。
- 交付前必跑：`npm run check`（preflight：隐私扫描 / `tsc --noEmit` / `electron/*.js` node --check / vitest / 后续门）、`npm run test:unit`、`npm run build:renderer`。

### 2.4 权限与数据

| 问题 | 用户拍板 / 队长处置 |
|---|---|
| 能否 bump `VAULT_SCHEMA_VERSION` 4→5 | **已授权**：走 P-1 契约修订 + Q7 裁决记录（含 C-42/C-43 论证、5 条既有断言改写方案） |
| 能否改契约文档 | 授权：只在 `docs/契约-本地测试资产工作站.md` 追加「录制域」小节 + 修订记录，**不改既有条款正文** |
| 能否写生产/真实数据 | **不涉及**：录制只用临时 `--user-data-dir`，不碰用户日常 profile；测试页用本地桩页 + `data:` 内联页 |
| 敏感数据 | `type=password` / `contenteditable` 页内只回 `{length}`；主进程对事件载荷**零 console 输出**（`app-log.js:69-71` 会劫持 console 落盘）；产物只写 `valueRef` 环境变量名 |

### 2.5 非功能

| 项 | 目标 |
|---|---|
| 元素级校验耗时 | 单元素 < 50 ms（上游单次观察 0.8 ms，属**量级证据**非分布） |
| 录制期内存 | 录制过程不落盘，仅在「保存」时写一次；单份 ≤ 300 步、单库 `maxItems: 20 / 1536 KB` |
| 端口安全 | `--remote-debugging-port=0` + 读 `DevToolsActivePort`，**禁止**「先探空闲端口再传参」（TOCTOU） |
| 清理 | stop / 强杀后 3 秒内无孤儿 `chrome.exe`、临时 profile 已删；应用启动时扫残留 |
| 兼容 | 只 Chromium 系（CDP）；Firefox/WebKit 明确不支持并在界面提示 |

## 4. OUT_OF_SCOPE（本期明确不做，后续任何阶段不得当遗漏补回来）

| 不做 | 依据 |
|---|---|
| **Python / pytest 产物** | 契约 `:1056` 明确「本批不做」；可行性报告 E-04 判为阻断 |
| 应用内**正式回归**（spawn `npx playwright test` / `java -cp`） | 要把 node_modules 或 JDK 塞进安装包；改为「一键复制运行命令」 |
| 自研 auto-wait / 复杂断言 / trace / 视频 / 截图 diff | 等于重写 Playwright；P3 冒烟回放整体延后 |
| **iframe（含同源）** | 一期只主 frame；`Target.setAutoAttach` 未验证，进本期等于带一个未验证机制开工 |
| 多 tab 录制 | 同上，界面明示「该区域不支持录制」 |
| 步骤可视化编辑（拖拽/时间线/分支循环） | 原报告 §1.3 已排除 |
| 跨浏览器（Firefox / WebKit / 真机） | CDP 绑定 Chromium 系 |
| 元素库**一键体检**（批量 L1） | P1 内容（AC-11）。本期只落「上次校验」字段并显示，不做批量入口 |
| 云录制 / 多人协作 | 与「数据不出本机」冲突 |
| 字段级 schema 校验扩张 | 契约 C-23 `:131`，不得借录制顺手加 |
