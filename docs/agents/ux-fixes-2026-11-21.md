# 方案：背景图玻璃层补漏 + 占位符截断 + 笔记/SQL 片段区分（2026-11-21）

> 状态：staged（待批准）。上一轮团队 `css-layers-and-polish` 已归档，本轮是新团队 `ux-fixes-1130`。
> 用户报的三个问题 + 两条已确认的取舍，全部落到下面三块。

## 目标

1. 背景图模式下**没有真正的不透明表层**（除了主按钮/键帽这类本就该实心的控件）。
2. 输入框占位符不再被硬裁成半截。
3. 「笔记」与「SQL 片段」在列表、图标、新建入口三处都能区分。

## 范围

**做**

| # | 问题 | 落点 | 已确认做法 |
|---|---|---|---|
| 1a | 4 处真漏 | `src/styles/redesign.css` 的 `html[data-bg='image']` 段 | 补 `tag-sidebar-search` / `search-scope-btn` / `view-toggle-btn` / `tb-main-head` 进玻璃覆盖 |
| 1b | 浅色主题背景图被白雾冲淡 | `src/styles/redesign.css` 的 `.app-bg-dim` | 浅色主题下按比例减淡：`opacity: calc(var(--bg-dim) * 0.67)`（42% → 28%），滑块仍可调 |
| 2a | 占位符文案过长 | `src/components/toolbox/JsonTool.tsx:165` | 缩到「粘贴 JSON，支持单引号 / 无引号键 / 注释 / 多余逗号」 |
| 2b | 占位符字号 | `src/styles/redesign.css` | `::placeholder` 字号降一号（`--fs-xs`），仅在短文案仍可能贴边的地方 |
| 3a | 列表区分 | `src/pages/Notes.tsx` | 列表项前加类型图标（笔记=文档 / SQL=数据库）+ 标题后一个 `Pill` 徽标 |
| 3b | 新建时区分 | `src/pages/Notes.tsx` | 新建入口拆成「新建笔记 / 新建 SQL 片段」两个动作，预置 `kind`（`emptyNote('sql')` 已有） |

**不做（OUT_OF_SCOPE）**

- 不动 `--glass-*` 的整体不透明度（用户选的是「补漏 + 浅色压暗降一档」，不是整体再降）。
- 不改主按钮 / KBD / 危标这类**本应实心**的控件（扫描里出现的 `btn-add` / `btn-empty-add` / `KBD` 不算漏）。
- 不动笔记的存储格式、`utils/noteKind.ts` 的判定规则、目录扫描上限（读 20 个正文的那条）。
- 不做笔记正文的 SQL 语法高亮（那是新功能，不是「区分」）。

## 选型取舍：浅色压暗怎么实现

| 方案 | 团队能力 | 生态 | 维护成本 | 结论 |
|---|---|---|---|---|
| A. 改默认值 0.42 → 0.28（`settings.backgroundDim` 三处默认） | 5 | 5 | 3（深色也一起变淡，且改了已存用户的数据语义） | 否 |
| B. CSS 按比例减淡：`html[data-theme='light'] .app-bg-dim { opacity: calc(var(--bg-dim) * 0.67) }` | 5 | 5 | 5（不动数据、深色不受影响、滑块仍生效） | **选 B** |
| C. 浅色下换一种遮罩（渐变/负片） | 2 | 2 | 2 | 否 |

选 B 的代价：滑块显示 42% 但浅色下实际 28%，需要在滑块旁标一句「浅色主题下自动减淡」，
否则用户会以为设置没生效。

## 模块与改动点

```

src/pages/Notes.tsx       列表项图标 + Pill 徽标；新建入口拆两个动作（笔记 / SQL 片段）
src/components/toolbox/JsonTool.tsx:165   placeholder 文案缩短（aria-label 保留全文）
```

## 契约

- 不改 IPC、不改 vault 结构、不改 `Note.kind` 枚举与 `fileOf`（`.sql.md` 命名约定不变）。
- 新建 SQL 片段仍走 `emptyNote('sql')` + `fileOf(title,'sql')`，文件名后缀不变（`kindDecidedByName` 依赖它）。
- 玻璃补漏只加背景色引用，**不加 `backdrop-filter` 到容器**（`check-stacking.js` 会拦）。

## 风险

1. **补漏后仍有观感差异**：4 处补完，扫描里可能还有面积 <600 的小元素漏网。缓解：修完用同一支扫描脚本复扫，要求「除黑名单（`app-bg-dim`/主按钮/KBD）外 0 个不透明块」。
2. **浅色减淡过头**：28% 白雾下，标签栏/表头文字对比度可能掉到 AA 边缘。缓解：qa 在浅色+背景图下量文字对比度（正文 ≥4.5:1，弱化文字 ≥3:1）。
3. **新建入口拆两个按钮挤占页头**：`.page-head` 已经有搜索/刷新/导出。缓解：用下拉或次级按钮组，qa 量页头一行是否换行（1080p 宽 ≥1280 不换行）。

## 里程碑

- 必须当期：1a/1b（观感问题用户已经报了两轮）、3a/3b（功能区分）。
- 可延后：2b 的字号统一到全局 `::placeholder`（先只改 JSON 工具这一处，避免影响 30 个输入框的紧凑布局）。
