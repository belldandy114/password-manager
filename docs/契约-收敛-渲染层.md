### 3.3 `.jtl` 页签在 PerfTest 的落位（含「不嵌套 tabs」约束）

**落位**：`src/pages/PerfTest.tsx` 的右栏 `section.perf-main` 顶部加**一条** `.tabs` / `.tab2` 页签条，两个页签：

| 序 | 页签文案 | 内容 |
|---|---|---|
| 1（默认） | `运行结果` | 现有的「实时控制台」+「结果」面板 +「运行历史」面板（原样，不拆不改） |
| 2 | `.jtl 指标` | `<JtlTab addToast={addToast} />`（用 PerfTest 既有的 `useToast`，**不新增第二个 `ToastContainer`**） |

**硬约束**：

1. **不嵌套 `.tabs`**：压测页只允许这一条 `.tabs`；`JtlTab` 内部只有 `<Panel>`，不得出现 `.tabs/.tab2/[role=tablist]`。页签内容不做二次分栏切换。
2. **默认页签必须是「运行结果」**：`scripts/ui-round10-test.js:240-244` 断言 `.perf-console-head .pnl-title` 文案 === `实时控制台`，且 :214-231 统计 `.perf-page .pnl` 的「`pnl-body` 被裁切」数量为 0。默认落 `.jtl` 会让控制台断言直接红。
3. **非激活页签用条件渲染（不挂载），不要 `hidden` 并存**：`.perf-page .pnl` 的裁切断言把整页所有 `.pnl` 都算进去，并存会引入一批隐藏面板的噪声统计；条件渲染让非激活页签里的 `Panel` 根本不在 DOM 里，断言保持现在的语义。
4. **禁用 `.perf-tab` 类名**：`scripts/ui-jmxlib-test.js:191` 断言 `document.querySelectorAll('.perf-tab').length === 0`（历史上压测页有过页签后被移除）。新页签一律用既有 `.tabs` + `.tab2`。
5. **页签 id / a11y 命名**：`id="perf-tab-<id>"`、`aria-controls="perf-panel-<id>"`、`tabpanel` 带 `aria-labelledby`、`role="tablist"` + `aria-label="压力测试结果视图"`，`tabIndex` 非激活为 `-1`（照 `src/pages/ResultHub.tsx:47-67` 与 `CodeGen.tsx:62-80` 的既有写法，本项目全部页签都是这个形状）。
6. **不改文案**：页签文案就是「运行结果」「.jtl 指标」；`JtlTab` 的三块面板标题（`① 取数` / `② 总览指标` / `③ 按接口`）原样搬，**不要重编号**——重编号会与 §3.4 的「逐字段一致」验收打架。
