## 0. 使用规则（先读这一节，它决定后面的条目怎么用）

### 0.1 三种判定，只有一种算通过

| 符号 | 含义 | 能否汇总成「通过」 |
|---|---|---|
| ✅ | 命令跑过、退出码 0、输出贴在报告里 | 可以 |
| ❌ | 命令跑过、判据不成立 | 可以（结论=不通过） |
| ⚪ | **没跑**（环境前置缺失 / 路径不可达 / 时间不够） | **不可以**。⚪ 只能出现在「未验证清单」里，写成「未验证：<原因>」 |

三条硬规则：

1. **拿退出码说话，不拿截图说话**（契约 `[M-4]`）。布局类断言用 `scripts/ui-*.js` 的几何断言，不用人眼。
2. **不许为了让门变绿而改断言**。判据（`toContain` 的字符串、golden 的字节）是从契约抄下来的；
   断言与契约不一致时，改的是实现或契约定稿流程，不是把断言改成现状。
3. **门证据必须对应当前文件版本**。改了文件之后没重跑对应的门 = ⚪，不是 ✅（`stale` 语义）。

## 5. 手工路径（步骤 + 预期；只有 ⚪/✅ 两种结果，不许写「看起来正常」）

> 手工步骤也要求贴证据：命令输出、`tasklist`/`netstat` 原文，或截图 + 断言到的文本。**「我点了，没问题」= ⚪。**

**M-1 点验一条真实落库元素（含登录态）**
1. `npm run build:renderer && npm start`；解锁密码库 → 元素库 → 选中一条 `kind=role` 且已保存的元素；
2. 点「▶ 点验」，在**打开的浏览器窗口**里完成登录 → 再点一次；
3. 预期：面板出 `total ≥ 1`、`reason='ok'`、`label ≤ 40 字`、浏览器里命中元素被高亮；`approx` 对 `role/text/pw` 显示「近似口径（与 Playwright 实现不完全等价）」。
   **判失败**：出现 0 命中且文案是「没命中」而实际是没连上（`[A2-4]`）；或页面未登录时把 `login-required` 说成 `not-found`。

**M-2 不误杀用户浏览器（安全红线，最高后果）**
1. 手工开一个**普通** Chrome/Edge（随便打开一个网页，输入框里打几个字不要提交）；
2. 在应用里跑一次点验（`M-1`），然后 `stop`；
3. 预期：应用拉起的那个窗口关闭；**手工开的那个浏览器仍在、输入的内容还在**；`tasklist | findstr chrome` 里手工那个 pid 仍存活。
   **判失败**：手工浏览器被关掉（`[A2-10]` 的双校验失效，等于用户未提交的表单丢了）。

**M-3 干净退出（端口 + profile + pid 文件）**
1. 跑一次点验并记下端口（面板 `session.port`）；
2. `stop`；立刻（≤3 秒）执行：
   ```powershell
   netstat -ano | findstr :<PORT>          # 预期：无输出
   tasklist /FI "IMAGENAME eq msedge.exe"  # 预期：无本次 profile 的进程
   Test-Path "$env:APPDATA\<数据目录>\el-hit-profile\pm-hit.pid"   # 预期：False
   ```
3. 预期：三条如上；`el-hit-profile` **目录仍存在**（会话间复用登录态）。
   **判失败**：端口仍监听 / 孤儿进程 / pid 文件残留。

**M-4 退出应用即关闭**
1. 起一次点验（浏览器窗口打开）→ 直接关闭应用（或托盘退出）；
2. 3 秒内 `tasklist | findstr msedge` + `netstat`：预期无本 profile 进程、无端口。
   **判失败**：应用关了但 `el-hit-profile` 的浏览器还在（= 留了个对本机全开的调试端口）。

**M-5 锁定即关闭 + 不阻塞**
1. 起一次点验 → 界面「锁定」；
2. 预期：锁定**立即**完成（≤3 秒，不得卡住）；浏览器窗口随之关闭。
   **判失败**：锁定时界面卡 >8 秒；或锁定后浏览器还在（此时主进程已拿不到 vault 明文，`pageId+elementId` 来源已失效）。

**M-6 审计脱敏**
1. `M-1` 跑完后打开 `<数据目录>/logs/audit.log`，找 `"action":"el-hit-session"`；
2. 预期：该条**恰好 8 个键**；`"host"` 只有域名+端口，**没有** path / `?query`；**没有**元素名 / `label`；
   全条不含 `C:\\Users\\<用户名>`。
   **判失败**：出现完整 URL、query、元素名，或第 9 个键。

**M-7 `visible` 口径（`opacity:0` 算可见）**
1. 造一个页面：`<button id="a" style="opacity:0">隐藏按钮</button>` 与 `<button id="b" style="display:none">不显示</button>`，用 `file://` 打不开（`[A2-2]` 只放行 http）→ 用任意本地 http 静态服务（如 `npx http-server`）托管；
2. 分别点验 `#a` 与 `#b`；
3. 预期：`#a` → `visible:true`、`reason='ok'`；`#b` → `visible:false`、`reason='not-visible'`。
   **判失败**：`#a` 报不可见（与 Playwright `isVisible()` 口径分裂，等于面板上的「可见」和试跑回填对不上）。

**M-8 A₀ `javac` 编译（jar 就绪时才可执行，否则记 ⚪）**
1. 取 Playwright Java jar（见 §7）；
2. 对 6 份 golden 逐份执行 §7 的 `javac` 命令；
3. 预期：6/6 退出码 0，输出里无 `error:`。
   **判失败**：出现 `error:`（含 `cannot find symbol` —— 那正是「调用了一个 Playwright 不存在的 Java 方法」，`label` / `testid` 等新 kind 最容易在这里暴露）。

**M-9 A₁ 三语言粘贴（界面）**
1. 元素库 → 粘贴导入，分别粘 JS / Python / Java 三份 codegen 片段（每份含 `getByRole` / `getByLabel` / `getByTestId` / 带 `filter` 的链）；
2. 预期：各得同构的候选条数；预览表只读回显 `识别为 Python 定位行` 之类文本；「N 行未识别」与夹具一致；**没有**语种下拉。
   **判失败**：任一语言得 0 条；或 `getByLabel` 显示为 `pw`；或未识别行被静默吞掉。
