### 1.2 用户可感知的行为变化

1. **元素库定位方式 5 → 10 种**：新增 `label` / `placeholder` / `alttext` / `title` / `testid`，均可生成 Java POM。
2. **粘贴导入支持三语言 codegen**：Playwright codegen 的 **JS / Python / Java** 三种 Target 输出都能识别成元素库候选；动作行忽略、重复去重、跨语言去重成立。

   - `element-args.js` role 分支参数颠倒 → 此前 **role 元素试跑必然 0 命中**；
